# KJV ↔ JPS 1917 map, version 1

`kjv-jps1917.v1.json` is bound to the corpus revisions in the bundled manifests.
Load it with `loadVersificationMap` and a provider-backed verse-boundary callback.
The loader checks revisions, actual reference existence, and disjoint entries.
The corpus test also proves that every verse in both editions is classified once.

The baseline is SIL Global's English-to-BHS table, pinned to libpalaso commit
`b4f7a6da7b868f9ae909e40fb0708f5fd4efd782`. `eng.vrs.txt` and `org.vrs.txt`
are retained verbatim; their SHA-256 hashes and the exact upstream URL are in the
map. The adjacent MIT license also ships under `resources/bible/`.

Run `python3 scripts/import-bible/generate-map.py` after an intentional corpus
update to regenerate the map from these tables and the local SQLite database.
This command never fetches. Review generated changes, then run the import and tests.
If an intentional source update makes import fail the corpus-revision check, its
new staged database remains in `data/raw/margin-bible.build.sqlite`. Regenerate
against it with `--database data/raw/margin-bible.build.sqlite`, review the mapping,
and rerun import. Never regenerate to bypass a source-checksum mismatch.

Adaptations checked against the imported words:

- Exodus 20 and Deuteronomy 5 combine four commandments into one JPS verse.
- 1 Samuel 20:42 splits across JPS 20:42 and 21:1.
- 1 Kings 18:33–34 forms an inseparable two-verse group; 22:43 splits in JPS.
- 1 Chronicles 12:4 splits into JPS 12:4–5.
- Psalm 13:5–6 combines into JPS 13:6.
- Isaiah 63:19–64:1 combines into JPS 63:19.
- KJV Nehemiah 7:68 (horses and mules) has no text in this JPS export and is unmapped.
- Numbered JPS psalm titles have no KJV verse-zero token counterpart: the KJV
  source stores these as unnumbered `d` metadata. These 67 JPS verses are explicitly
  unmapped. Titles included inside an ordinary JPS verse remain in that source verse.
- All 7,957 New Testament KJV verses are explicitly unmapped to JPS.

Each entry is a semantic group of whole verses, not a positional zip. Selecting
part of a group's multi-verse side produces `confirmation-required`, with both
source and target groups. `incomplete` returns explicit missing refs and reasons.
Callers must present these results before changing translations. Mapped results
are ordered, deduplicated, and compacted using actual chapter boundaries.

## Five-edition switching

`edition-maps.v1.json` contains compact exceptions for all ten pairs among KJV,
JPS 1917, BSB, WEB, and ASV 1901. It is generated by
`scripts/import-bible/generate-edition-maps.py`, using this reviewed KJV/JPS map and
the exact imported inventories. Matching references are implicit only outside
explicit split/merge groups and only when both editions contain verse text.
WEB Romans 14:24–26 maps to the other English editions' 16:25–27. Missing verses
stay unmapped and require the reader to confirm before using a partial range.
All corpus revisions are checked on load. See `resources/bible/README.md` for the
regeneration and validation steps.
