## Remaining release caveats

- Local build only: nothing published, installed over the user's app, committed,
  or merged. The existing versioned artifact filenames were replaced.
- No Developer ID signing or notarization. The first build of the day was only
  linker-signed (`CSC_IDENTITY_AUTO_DISCOVERY=false`), so its bundle signature was
  invalid and a fresh Mac reported it as "damaged". The rebuild sets
  `mac.identity: "-"` and `hardenedRuntime: false`, so electron-builder ad-hoc
  signs the whole bundle. `codesign --verify --deep --strict` passes on the app
  and on a copy taken from the DMG, and the packaged e2e test passes. Gatekeeper still
  rejects it (no Developer ID), so the first open needs System Settings → Privacy &
  Security → Open Anyway. Notarization is the real fix.
- The documented evaluation licence expires **November 21, 2026**. Passing
  today's packaged test is not a permanent production licence approval.
- BDB integration and the larger word-lookup accuracy plan remain separate work.
- The website builds, but its download URL, repository URL, and contact email
  remain unset in `site/lib/site.ts`.
- Update delivery remains deliberately deferred; no updater was added.
